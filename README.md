# 贷后管理看板

一个给对公客户经理用的手机网页，所有功能都在 `index.html` 这一个文件里，不需要安装任何东西。

## 功能

- **看板**：显示本季度“访问 x/n、报告 x/n、关注/风险户数”，以及距季末剩余天数
- **自动标红置顶**：季末前 15 天内，贷后访问或贷后报告还没完成的客户会标红并排在最前面；已经结束的季度里没完成的会标“逾期未完成”
- **每季度三项进度**（点客户卡片即可修改）
  - 贷后访问：未开始 / 已约 / 已完成（访问日期、访问要点）
  - 贷款情况：正常 / 关注 / 有风险（备注）
  - 贷后报告：未写 / 草稿 / 已提交
- **切换季度**：顶部 ‹ › 或点季度名称，查看往季记录
- **客户管理**：添加、编辑、删除客户（企业名称、贷款金额、放款日、到期日、还款方式）
- **备份**：导出 Excel（.xlsx）；下载 / 恢复备份文件（.json）

首次打开会自动载入 5 家演示客户。正式使用前，到“备份”页点“清空全部数据”，再到“客户”页添加真实客户。

## 在手机上打开

### 方法一：GitHub Pages（推荐，得到一个固定网址）

1. 在电脑或手机浏览器登录 GitHub，打开本仓库
2. 进入 **Settings → Pages**
3. “Build and deployment” 中 Source 选 **Deploy from a branch**，Branch 选放有 `index.html` 的分支（合并到 `main` 后选 `main`），文件夹选 `/ (root)`，点 **Save**
4. 等 1～2 分钟，页面顶部会出现网址，一般是 `https://daihou-hue.github.io/Daihou/`
5. 用手机浏览器（Safari / Chrome / 系统自带浏览器）打开该网址，再“添加到主屏幕”，以后像 App 一样点开就能用

> 免费账号的 GitHub Pages 要求仓库是公开（Public）的。网页本身是公开的，但**你录入的客户数据只存在你自己手机的浏览器里，不会上传到任何地方**，别人打开同一网址看到的是空白或演示数据。

### 方法二：直接把文件发到手机

把 `index.html` 下载下来，通过文件传输发到手机，用手机浏览器打开即可。（部分手机的文件管理器打开本地网页时下载功能受限，推荐方法一。）

## 注意事项

- 数据保存在**当前手机的当前浏览器**里。换浏览器、换手机，或清理浏览器缓存/网站数据，数据会丢失，请定期在“备份”页下载备份文件。
- 不要用无痕/隐私模式打开，否则关掉后数据不会保留。
- 微信里打开无法下载文件，请点右上角“…”选择“在浏览器打开”。
- Excel 只用于查看和存档；要把数据恢复到手机上，请用 .json 备份文件“从备份文件恢复”。
